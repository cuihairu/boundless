# Reference

Look-up material: what the configuration keys mean, what the command line
accepts, and which items each crate exports.

## Sections

- [Configuration reference](/reference/configuration) — the `bw.xml` chain, the
  `+key value` overrides, the option table and resource paths.
- [CLI reference](/reference/cli) — the one executable, its role argument, the
  resource flags and exit codes.
- [Script and SDK API](/reference/api) — the public surface of every crate, each
  with the `cargo test` command that proves it.

## What "reference" means here

These pages describe the code that exists in this tree. Where the reference
revision had a concept this tree has not ported yet, the page names the
`todo.md` id tracking it instead of documenting something that is not there.
