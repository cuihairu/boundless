## 移植语义（逐句核对）

1. **布局定案（本任务最关键勘误）**: 头 16B（token+三尺寸）+ counts
   12B + **包围盒 32B**（min 12 + max 12 + 两个零 `Outcode` 字——
   `saveBSPInMemory` 写 `sizeof(BoundingBox)`，`loadBSPCurrent`
   `readPOD(boundingBox_)` 原样读回）+ 三角形 nt×40 + shared nsh×4 +
   节点 nn×40 + 用户数据。早期把盒当 24B 会整体错位 8 字节——真资产
   `unit_cube.bsp` 在 32B 下精确闭合（60+480+80=620，零余字节）。
   移植端保 min/max、弃两个 outcode 渲染字。
2. **偏移是元素下标，不是字节**: `offsetToPtr` 是 `basePtr + offset`
   （`WorldTriangle*`/`BSPNode*` 指针算术）——shared 偏移、节点
   front/back、节点三角形/_shared 基址一律元素单位；`-1`=NULL→None，
   其余负值 `MF_ASSERT`→panic（catch_unwind 钉死）。引擎自存文件
   `legacy_saved.bsp` 的 shared 偏移 (0,1)→t0,t1 为实证。
3. **validate 恒跑**: `BSP_RUNTIME_VALIDATION` 无条件定义——空/非空
   run 一致性、run 越界、子偏移越界、`numNodes == 1+Σ子链`、
   `numSharedTrianglePtrs == Σ numShared` 全部 `MF_ASSERT`→移植端
   panic（catch_unwind 钉死）。
4. **恒死分支照抄**: `getBSPVersion` 掩码分支 `(token & 0xffffff00)
   == BSP_FILE_MAGIC` 恒假（掩码剥掉魔数低字节 0x42）→ `loadBSP`
   的 "Unsupported bsp version" default 臂结构性不可达；两处按原样
   移植（clippy `bad_bit_mask` 以 allow+注释登记）。版本 token 测试
   钉死：版本 3 token → `INVALID` → BadMagic 原文。
5. **尺寸不符走宽限分支**: 参考 `MF_ASSERT` 后紧跟 `ERROR_MSG`+NULL
   宽限臂；移植端只保留宽限臂，报 `SizeMismatch` 原文
   "Failed to load bsp due to base structure sizes mismatch"。
6. **OOB 即报告（登记分歧）**: 头内 `readPOD` 无界断言、三角形/
   shared/节点数组级 `MF_ASSERT` 之前的直读、legacy 跳走与用户数据
   盲读——参考越界读处移植端报 `Truncated`（与 height/hole/dominant
   同一登记）；负长度用户数据参考在分配处崩溃→移植端 panic。
7. **legacy 转换 = 构造器导出**: 每三角形参考者表（节点序），
   `MF_ASSERT` 全有主；`std::sort` 用 `WorldTriangleRef::operator<`
   （严格前缀⇒相等）；移植端稳定 `sort_by` + 前缀相等比较器复刻
   libstdc++ 插入排序（夹具量级；更大输入走不稳定 introsort——
   登记）。首节点 run 归属、numShared 计数、shared 布局按节点序
   铺设再按参考者序回填。
8. **legacy 跳走**: 逐记录消费 17B+2·numRef、peek 下一节点 flags、
   深度记账，back = i + numSkipped + 1；仅 HAS_BACK（无 FRONT）⇒
   back = i+1。u16 三角形索引逐个 `MF_ASSERT` 越界→panic。
9. **三角形面**: 40B 行编解码（padding 清零/忽略）、flags 字低字节
   碰撞/高字节材质（`packFlags` 掩码低字节照抄）、`normal()`
   `(v2-v0)×(v2-v1)` 参考叉积序（(3,-3,0) 真值钉死）、
   `v(index)` 断言、`canCollide`=任一三角形碰撞字节 ≠ 0xff。
